# Comparison pictures

Drop one picture per volume-comparison rung into this folder. The session
summary shows the picture of the highest rung your total volume reaches,
below the fun comparison line.

Naming: `<slug>.<ext>` — any of `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`
(tried in that order; the first that loads wins). A missing picture is
fine: the card simply shows the text only.
